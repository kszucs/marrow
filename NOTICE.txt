Attribution is owed here for code marrow *redistributes* -- copied or ported,
since a port is a derivative work. It is not owed for dependencies marrow merely
uses and does not ship: the dev-time oracles (pyarrow, python-xxhash), the test
and build tooling, and the compression codecs (zstd, snappy, lz4, zlib, brotli)
which are opened at runtime via dlopen and never bundled. Snappy is also ported,
in marrow/utils/snappy.mojo, and that port is listed below.

A Mojo dependency is different: it is compiled into every binary that imports
it, the Python extension included, so marrow redistributes it in that form and
its notice is reproduced below like a port's.
