================================================================================
Binary distributions
================================================================================

A wheel, and a directory written by `marrow compile --bundle`, also contain the
libraries below. None of them is covered by marrow's Apache licence: each is
distributed, unmodified, under its own licence, whose full text is in the file
named, under `licenses/` -- in a wheel, `marrow-*.dist-info/licenses/licenses/`.
`LIBRARY_LICENSES` in python/marrow/compile.py maps each library to its texts,
and `python -m devkit wheel check` refuses a wheel where one is missing.

--------------------------------------------------------------------------------

    libKGENCompilerRTShared, libAsyncRTRuntimeGlobals, libMSupportGlobals
    (from the `mojo-compiler` package) and libAsyncRTMojoBindings (from
    `max-core`), linked by every Mojo-built binary.
    licenses/modular-LICENSE.txt, licenses/modular-Third-Party-Notices.txt

    Which terms govern redistributing these is awaiting Modular's written
    confirmation; marrow publishes no wheel until it has one.
